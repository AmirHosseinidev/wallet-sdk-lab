# Wallet SDK Lab

A test digital wallet SDK built with TypeScript, Node.js, and NestJS.

## Project Structure

- `apps/api`: NestJS backend and wallet API
- `apps/demo`: HTML, Tailwind CSS, and JavaScript demo
- `packages/sdk`: TypeScript Wallet SDK
- `docs`: Project documentation

## Features

- Wallet information
- Wallet balance
- Transaction history
- Currency exchange simulation
- Test transfers

## Important

This project is a demonstration and testing environment.
It does not process real payments or hold real funds.

## Requirements

- Node.js 22+
- npm 10+
- Git
